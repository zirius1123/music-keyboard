# My Personal Midi Keyboard

## Components
I made a basic MIDI keyboard. This MIDI keyboard consists of the following:
-  3 LEDs
- 2 Slider Potentiometors
- 1 Rotary Potentiometor
- 6 Switches
- 1 Microcontroller
- 5 Touch Pads
- Some illustrations of halflife, hack club, and gato

## Explaining my PCB
The keyboard is centered around the Waveshare ESP32-S3-Zero. I used JLCPCB for the PCB production. I am using Aliexpress for the components needed.
